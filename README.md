# Javavisual_tp03_253303621207
Character Manager adalah aplikasi berbasis Java Swing yang dirancang untuk mengelola data karakter secara visual dan terstruktur. Aplikasi ini memungkinkan pengguna untuk melihat daftar karakter, memantau level rata-rata secara langsung, serta memeriksa status kesehatan dan aktivitas karakter melalui metode yang tersedia.
